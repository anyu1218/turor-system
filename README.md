# 家教预约服务系统

> 基于 SpringBoot + Vue 的多端家教预约平台

## 项目简介

家教预约服务系统是一款面向学生、教师、管理员三方的在线预约平台，解决传统家教服务中的信息不对称、预约流程繁琐、资源匹配低效等痛点。

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | SpringBoot + Spring MVC + MyBatis |
| 前端 | Vue.js + Element Plus / Ant Design Vue |
| 数据库 | MySQL 8.0 |
| 认证 | JWT + Spring Security |
| 构建 | RESTful API（前后端分离） |

## 功能模块

### 学生端
- 账号管理（注册、登录、密码找回、个人信息维护）
- 教师筛选（按学科、年级、教学经验、价格多维度查询）
- 课程预约（选择教师和时段提交预约）
- 订单管理（查看状态、取消预约、课后评价）

### 教师端
- 账号与资质管理（注册、资质提交、个人信息、授课定价）
- 订单处理（接收预约、查看订单、提交授课完成状态）
- 课程管理（上传教学资料、查看评价、调整可授课时段）

### 管理员端
- 用户管控（审核教师资质、启用/禁用账号）
- 资源与订单监管（审核课程信息、查看订单数据、处理纠纷）
- 数据统计

## 核心难点

**并发订单处理**：多个学生同时预约同一教师的同一时段时，需避免订单超售。采用并发控制机制，确保先提交的申请优先响应，后续请求即时反馈"时段已被占用"。
